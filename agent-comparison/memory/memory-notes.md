# Agent Memory

## Short-Term Memory

Short-term memory stores the current conversation context.

Example:
- previous user questions
- previous tool outputs
- recent chat history

Used for:
- conversational continuity
- follow-up questions
- temporary reasoning

---

## Long-Term Memory

Long-term memory stores persistent information.

Example:
- user preferences
- saved notes
- vector database memory

Used for:
- personalization
- retrieval systems
- agent learning

---

## Day 14 Implementation

This project uses:

- array-based memory
- conversation history tracking
