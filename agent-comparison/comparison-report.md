# Agent Framework Comparison

| Feature | LangChain | LlamaIndex | Custom SDK |
|---|---|---|---|
| Ease of Use | High | Medium | Medium |
| Flexibility | Medium | Medium | Very High |
| Tool Calling | Built-in | Built-in | Manual |
| Memory Support | Good | Good | Fully Custom |
| Complexity | Medium | Medium | Low |
| Performance | Moderate | Moderate | Fast |
| Best Use Case | Rapid agent development | RAG systems | Understanding agent loops |

---

# Observations

## LangChain
- easiest for tool orchestration
- clean abstractions
- good ecosystem

## LlamaIndex
- excellent for retrieval systems
- stronger for document querying
- more RAG-focused

## Custom SDK
- best for understanding agent internals
- maximum flexibility
- minimal abstraction
